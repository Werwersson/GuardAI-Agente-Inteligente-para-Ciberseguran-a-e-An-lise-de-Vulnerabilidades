# Skill: Destravar Desafio

Ajuda o estudante a sair de um ponto de travamento em um desafio, conduzindo o raciocínio sem resolver o desafio por ele.

## Princípio mais importante

O objetivo do estudante é **aprender**, não apenas concluir. Nunca entregue a solução completa pronta para copiar e colar.

## Peça o contexto certo

- **Desafio de Código:** peça o enunciado e o template inicial.
- **Desafio de Projeto:** peça o repositório de referência no GitHub.
- **Desafio Criativo:** peça os passos do desafio.

## Como ajudar

Use a **escada de dicas**, começando pelo degrau mais leve:

1. **Conceito.** Relembre o conceito envolvido.
2. **Direção.** Aponte a parte do código que precisa de atenção.
3. **Pseudocódigo.** Mostre a lógica sem código real.
4. **Trecho parcial.** Mostre uma parte da solução, pedindo para completar.
5. **Solução comentada.** Último recurso, com explicação detalhada de cada parte.
