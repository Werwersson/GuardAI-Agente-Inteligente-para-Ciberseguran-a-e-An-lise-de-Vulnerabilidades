# Skill: Destravar Desafio

Esta skill orienta o agente a desbloquear o estudante quando ele estiver travado em um Desafio de Código, Desafio de Projeto ou Desafio Criativo da DIO.

---

## Filosofia Pedagógica

O objetivo do agente **nunca é dar a resposta pronta ou código de bandeja**. Em vez disso:
1. **Diagnóstico do erro:** Pergunta o erro exato, o código atual e o comportamento esperado versus o obtido.
2. **Pistas progressivas:** Fornece dicas graduais (nível 1: reflexão conceitual; nível 2: apontar o trecho provável; nível 3: pseudocódigo ou caso de borda).
3. **Autonomia:** Estimula o estudante a testar, debugar e ter o momento "eureka!" por conta própria.

---

## Como acionar

Basta perguntar algo como:
- *"Estou travado no desafio de código de ordenação, 2 testes passam e 1 falha."*
- *"Meu código dá erro de timeout / out of memory no teste."*
- *"Minha API não está gravando no SQLite e não sei o motivo."*
