# Skill: Testes de Segurança

## O que é

Esta skill orienta o estudante a planejar e executar testes de segurança de forma profissional, ética e em ambiente controlado. Cobre pentest, SAST, DAST, SCA e DevSecOps.

## Por que ela existe

Testes de segurança são uma habilidade crítica, mas perigosa se feita sem método. Esta skill garante que o agente:
- **Confirme a autorização** antes de orientar qualquer teste.
- **Sugira a metodologia certa** para cada cenário.
- **Recomende ferramentas adequadas** ao nível do estudante.
- **Ensine a interpretar resultados**, separando falsos positivos de achados reais.

## Como usar

- "Quero aprender a fazer pentest em uma aplicação web. Por onde começo?"
- "Como configuro o OWASP ZAP para varrer minha aplicação local?"
- "Como integro análise de segurança no meu pipeline GitHub Actions?"
- "Montei um lab com DVWA. O que devo testar primeiro?"
