# Glossário

Termos usados no projeto GuardAI Agent e em cibersegurança.

## Termos do Projeto

| Termo | Definição |
|-------|-----------|
| **Agente de IA** | Um sistema de IA que vai além de respostas simples: ele lê, planeja e executa passos para alcançar um objetivo. O GuardAI é um agente especializado em cibersegurança. |
| **Harness** | O programa onde a conversa com o agente acontece. O agente é o professor, o harness é a sala de aula. Exemplos: Hermes, Antigravity, Claude Code, Codex. |
| **Skill** | Um guia passo a passo em Markdown que ensina o agente a executar uma tarefa específica. Não é código — é um roteiro. |
| **Persona** | O "caráter" do agente: seus valores, tom de voz e limites. Definida em `agent/persona.md`. |
| **Knowledge** | Arquivos de conhecimento que o agente consulta para ter contexto. Ficam em `agent/knowledge/`. |

## Termos de Cibersegurança

| Termo | Definição |
|-------|-----------|
| **Vulnerabilidade** | Fraqueza em um sistema que pode ser explorada. |
| **Ameaça** | Circunstância ou evento com potencial de causar dano. |
| **Risco** | Probabilidade × Impacto de uma ameaça explorar uma vulnerabilidade. |
| **Exploit** | Código ou técnica que explora uma vulnerabilidade. |
| **CIA (Tríade)** | Confidencialidade, Integridade e Disponibilidade — os três pilares da segurança. |
| **OWASP** | Open Web Application Security Project — referência para segurança de aplicações. |
| **MITRE ATT&CK** | Framework que cataloga táticas e técnicas reais de adversários. |
| **CWE** | Common Weakness Enumeration — catálogo padronizado de fraquezas de software. |
| **CVE** | Common Vulnerabilities and Exposures — identificadores de vulnerabilidades conhecidas. |
| **SAST** | Static Application Security Testing — análise de segurança no código-fonte. |
| **DAST** | Dynamic Application Security Testing — análise de segurança com a aplicação rodando. |
| **SCA** | Software Composition Analysis — análise de dependências de terceiros. |
| **Pentest** | Teste de penetração — simulação controlada de ataque para encontrar vulnerabilidades. |
| **AppSec** | Application Security — segurança no ciclo de desenvolvimento de software. |
| **DevSecOps** | Integração de segurança nos processos de DevOps. |
| **Hardening** | Processo de fortalecer um sistema removendo superfícies de ataque desnecessárias. |
| **SQL Injection** | Ataque que insere código SQL malicioso via entrada do usuário. |
| **XSS** | Cross-Site Scripting — injeção de scripts maliciosos em páginas web. |
| **CSRF** | Cross-Site Request Forgery — forja de requisições em nome do usuário autenticado. |
